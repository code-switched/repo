Are you tired of spending precious minutes setting up new projects when you could be coding? Do you have more identities than a secret agent and struggle to keep them straight? Look no further! This repo is your one-stop shop for going from "lightbulb moment" to "coding like a caffeinated squirrel" in record time.

## Identity Crisis? No Problem!

We get it. You're not just a developer; you're a developer with multiple personalities (GitHub accounts, that is). Our scripts don't judge. They embrace your complex digital life and help you manage it with the finesse of a master spy.

## Features That'll Make You Go "Zoom Zoom"

- **repo_new.py**: Create a new GitHub repo faster than you can say "git init"
- **repo_existing.py**: Clone an existing repo with less friction than a greased-up bobsled
- **ssh_setup.py**: Set up SSH keys so securely, even your paranoid alter ego will be impressed
